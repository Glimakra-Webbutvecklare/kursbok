# Fördjupning: state och återanvändbar logik

Fördjupningen är frivillig. Börja först när Kulturverkstan fungerar med props,
lokal och lyft state, formulär, API och routing.

Här finns endast tre fortsättningsämnen:

- **Context:** när många avlägsna komponenter behöver samma värde.
- **Reducer:** när många stateförändringar behöver samlas i namngivna actions.
- **Custom hooks:** när fungerande hook-logik behöver återanvändas.

De här verktygen gör inte automatiskt en app bättre. Kulturverkstans kärnversion
ska fungera utan dem.
